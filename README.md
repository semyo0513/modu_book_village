# 🏡 책마을 : 우리 반 독서 빌리지 (Our Class Book Village)

> **알라딘 오픈API를 활용한 게이미피케이션 학급 독서 커뮤니티 웹앱**  
> 단순한 독후 기록장을 넘어, **릴레이·블라인드·피드·토론·성장(나무)**이라는 5가지 소통 방식을 하나의 따뜻한 동물의 숲 스타일 마을 콘셉트로 묶은 초·중등 학급용 웹 애플리케이션입니다.

---

## ✨ 핵심 기능

1. **🗺️ 2.5D 아이소메트릭 마을 메인 허브**
   - 도서관(검색/등록), 우체국(꼬리잇기), 광장(피드), 방송국(인터뷰), 비밀의 숲(블라인드), 중앙 거대나무, 내 서재로 구성된 감성 인터랙티브 맵.
2. **🎪 우리 반 한 줄 피드 (Bookgram)**
   - 인스타그램 스타일의 감성 독서록 피드.
   - 알라딘 독자 평점 vs 우리 반 평균 별점 비교 인디케이터 및 공감/위시리스트/감정 스티커.
3. **📮 책 꼬리잇기 (릴레이 라이브러리)**
   - 키워드와 연결 이유를 매개로 친구들의 독서 생각이 꼬리를 물고 이어지는 연결망.
4. **🔮 비밀의 숲 (블라인드 북 익스체인지)**
   - 표지와 제목을 숨긴 채 '생각 질문'과 '인상 깊은 문장'만으로 추리.
   - 댓글이 임계치에 도달하면 3D Flip 애니메이션과 함께 표지와 줄거리 자동 해금.
5. **🎙️ 책 속 인물 가상 인터뷰 & 핫비평**
   - 작성자가 주인공 페르소나를 맡고, 반 친구들은 학급 기자가 되어 댓글 인터뷰 진행.
6. **🌳 독서 나무 & 게이미피케이션**
   - 완독 1권마다 이파리/열매 성장 (개인 서재 나무 + 반 전체 중앙 랜드마크 나무).
   - 장르별 탐험가 뱃지 시스템.
7. **🏫 교사 관리자 패널**
   - 학생 명단 일괄 등록, 초기 비밀번호 자동 발급, 다독 랭킹 통계 및 부적절 글 삭제 관리.

---

## 🛠️ 기술 스택 및 아키텍처

- **백엔드**: Google Apps Script (`Code.gs`)
- **데이터베이스**: Google Sheets (8개 시트 구조, Books 캐시 포함)
- **도서 API**: 알라딘 Open API (서버측 프록시로 TTBKey 노출 방지)
- **프론트엔드**: HTML5, Vanilla JavaScript, Tailwind CSS (GitHub Pages 정적 호스팅 지원)
